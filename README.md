# Python System CLI Assistant

A modular Command Line Interface (CLI) tool designed to monitor system hardware telemetry and integrate local LLM capabilities.

## Features
-System Telemetry: Real-time CPU, RAM and Disk utilization tracking via psutil.
-Local LLM Integration: Connects to local Ollama API running Llama 3.2 models for offline AI assistance.
-Modular CLI: Lightweight architecture structured for easy feature expansion and command parsing.

## Tech Stack
-Language: Python 3 
-Libraries: psutil, requests
-Local AI: Ollama / Llama 3.2

## Setup & Running
1. Clone the repository: git clone https://github.com/h-akgul/python-system-cli-assistant.git
2. Install dependencies: pip install psutil requests
3. Run the application: assistant_cli.py
